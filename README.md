# Acharya AI Dojo — research track

A practice page for participants of *Japan Meets India AI Nexus 2026* (Bengaluru, 21–23 September 2026): three missions and thirteen drills on using AI assistants in research — reading with the page in your hand, establish-and-refute, and the 15-minute audit before you submit.

**Live page:** https://akiramurata-juntendo-code.github.io/acharya-ai-dojo/

Made and run by Dr Akira Murata (Juntendo University; co-founder, Awesome AI Asia). The name is used with the kind permission of the organisers at Acharya Institutes; the page is **not** an official service of the institute.

All example texts are fictional. The page has no forms, no analytics and no cookies; progress is stored only in the visitor's own browser (localStorage). This repository contains no personal data about participants.
