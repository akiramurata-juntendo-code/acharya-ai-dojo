# Acharya AI Dojo

A practice site for participants of *Japan Meets India AI Nexus 2026* (Bengaluru, 21–23 September 2026). A home page with two doors: a **Research track** (reading with the page in your hand, establish-and-refute, the 15-minute audit before you submit) and a **Student track**. Each track has three missions, short drills and its own belt.

**Live site:** https://akiramurata-juntendo-code.github.io/acharya-ai-dojo/ · [Research track](https://akiramurata-juntendo-code.github.io/acharya-ai-dojo/research/) · [Student track](https://akiramurata-juntendo-code.github.io/acharya-ai-dojo/students/)

Made and run by Dr Akira Murata (Juntendo University; co-founder, Awesome AI Asia). The name is used with the kind permission of the organisers at Acharya Institutes; the site is **not** an official service of the institute.

All example texts are fictional. The site has no forms, no analytics and no cookies; progress is stored only in the visitor's own browser (localStorage). This repository contains no personal data about participants.
